# Power BI Assistant V2 使用指南

Power BI Assistant 在本机连接已打开的 Power BI Desktop 报表。可以用它编写 DAX、调整 Power Query 步骤，或针对报表数据做一次可追溯的分析。

可从左栏「使用说明」离线查阅本指南。首次选报表前，欢迎页的「快速上手」会直接打开第一次提问的步骤。

**版本范围**　本文适用于 **2.0.13** 安装包与当前源码。2.0.13 增加桌面在线更新。2.0.12 引入的离线使用说明支持章节导航、关键词搜索和快速上手。历次发行件的验证范围见[验证记录](VALIDATION.md)。

发布者可查阅[授权与部署说明](LICENSING.md)，开发资料见[项目首页](../README.md)。

## 安装与启动

### 使用安装包

1. 准备 Windows 10/11 x64、Edge WebView2 Runtime 和本机 Power BI Desktop。安装版已包含助手运行所需依赖。
2. 运行 `PowerBIAssistant-Setup-2.0.13.exe`，在「软件授权」页复制本机机器码，请发布者签发 CD-KEY。粘贴完整密钥，按向导安装。
3. 从 Windows 开始菜单启动助手。默认程序目录为 `%LOCALAPPDATA%\Programs\PowerBIAssistant`。首次启动后需添加自己的 AI 服务并选择报表。

永久授权与 7 天试用均绑定机器。试用从签发时刻起算，授权页和试用窗口标题显示 UTC 到期时间。试用转永久时，关闭助手，使用同一机器码对应的永久 CD-KEY 重新运行安装包。

### 从旧安装版升级

使用 2.0.12 或更早版本时，关闭助手，用 2.0.13 安装包覆盖原安装位置一次。授权页会带入已有 CD-KEY，仍然有效即可继续。升级沿用原会话、业务词典、模型设置和试用到期时间。手动备份的位置见[备份与恢复](#备份与恢复)。

从 2.0.13 开始，已安装的桌面窗口会在启动时和持续运行期间每 6 小时后台检查新版，也可随时点左下角「检查更新」。看到新版后查看更新说明，点「更新并重启」。助手会先下载并校验安装包，完成后重新打开。正在运行的任务可先完成，下载中也可点「稍后」继续工作。未发送的草稿和附图请在重启前保存。离线时可以照常打开助手，恢复网络后可手动重试。

### 使用源码

在项目根目录打开 PowerShell，使用 Python 3.11 或以上版本。项目使用 Python 3.12 验证。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\.venv\Scripts\python.exe desktop.py
```

之后可双击根目录的 `start.bat`。源码桌面界面直接加载前端文件，无需 npm 构建。排查窗口问题时可运行 `.\.venv\Scripts\python.exe desktop.py --browser --port 8765` 在本机浏览器预览，结束时在终端按 `Ctrl+C`。安装版和源码版各有默认数据目录。

## 完成第一次提问

右上角的 **English** 可将界面和后续 AI 回复切换为英文，点 **中文** 可切回。助手会在本机记住选择。切换时可以保留当前草稿、附图和正在生成的回复。

1. 在 **Power BI Desktop** 打开你要分析的 PBIX，等待报表加载完成。
2. 在助手左下角打开「模型服务设置」，添加 AI 服务，点击「保存并测试」，成功后选「保存并使用」。该服务负责理解问题和生成回答。
3. 点击**助手右上角的报表连接按钮**，按报表名称和文件路径选择实例。成功后按钮显示「Desktop 已连接」，右侧「模型上下文」显示报表名、表、字段和度量值数量。右上角显示「等待 Desktop」时，同一按钮仍可点击。
4. 首次连接的真实模型若尚无业务解释，DAX 或数据分析会引导打开「模型语义层」。先梳理语义并审阅本次要用的指标，或填入已有业务定义，再继续提问。
5. 默认打开「DAX 助手」。从右侧插入报表中已有的度量值，在输入框写下「请解释这个度量值的计算口径，以及日期筛选会怎样影响它」。按 `Enter` 发送，`Shift+Enter` 换行。

在空白对话尚未选报表时，可以直接点「连接 Power BI 报表」。数据分析助手只有示例模型时也会显示这个入口。可以先写问题、贴截图，再首次连接。未发送的文字和图片会保留，连接后由你发送。有模型快照但原报表离线时，从右上角的状态按钮重新选择。

没有可用报表时，可在连接窗口选「体验示例模型」浏览字段和试用生成。生成仍需配置 AI 服务。实际取数、校准、实跑与写入都需要可用的 Desktop 实例。

按你的任务继续阅读[编写 DAX](#使用-dax-助手)、[清洗 Power Query 数据](#使用-power-query)或[分析报表数据](#查询数据并核对结果)。

## 配置大模型服务

从左下角「模型服务设置」或输入框下方的模型名称进入，点击「添加模型」。填写易识别的显示名称，并按服务端提供的信息选择协议。

| 设置 | 如何填写或判断 |
| --- | --- |
| API 协议 | 可选「OpenAI 兼容」或「Anthropic Messages」，与服务商提供的接口一致 |
| 服务器 API 地址 | 填服务商的 API 根地址。兼容服务常用形如 `https://模型服务域名/v1` 的地址。Anthropic 官方服务可留空 |
| 模型名称 / ID | 填服务端实际部署的模型 ID。需要分析截图时，选择支持视觉输入的模型 |
| API Key | 填该服务的凭据。内部兼容服务若无需鉴权，可填 `local`。编辑已有配置时，Key 留空会保留该条目的密钥 |

「仅保存」保存条目，「保存并使用」将其设为当前服务，「保存并测试」保存后发起一次真实测试请求。可在列表中切换配置。已提交的一轮生成继续使用提交时的服务。

### 思考强度与等待时间

初始思考强度为低。支持调整的模型可在配置卡片选择「低强度」或「高强度」。界面会注明该接口支持原生强度、仅支持开关或强度不可调。高级设置的默认值如下。

| 参数 | 默认值 | 可设范围 |
| --- | --- | --- |
| 单次输出额度 | 16,000 token | 256～131,072，以服务端容量为限 |
| 无新数据等待时间 | 90 秒 | 30～600 秒 |
| 单次生成总时限 | 900 秒 | 180～7,200 秒，且须大于或等于无新数据等待时间 |

遇到长度限制时，可缩小任务或提高输出额度。一直没有新数据时，先检查服务连通性和负载。思考过程可能消耗时间和输出额度。

## 连接和同步报表

连接窗口读取本机已打开的 Desktop 实例。多个报表名称相似时，应核对文件路径，连接后再看右侧字段。「同步模型」位于右侧模型面板标题旁。

| 界面状态或变化 | 下一步 |
| --- | --- |
| 找不到实例 | 打开本机 Desktop 报表，等其加载完毕再选「重新扫描」。仅在浏览器打开 Power BI Service 无法提供本地实例 |
| 正在检测连接 / 自动重连中 / 等待 Desktop | 打开原报表并等待恢复。持续等待时，点击右上角状态按钮重新扫描 |
| 请选择报表 | 存在多个可能的实例，手动选择目标报表 |
| 结构待同步 | 已改列名、度量值、关系或查询，点击「同步模型」。会话、图片、草稿和历史结果保留，同步前的回复会有标记 |
| 快照已释放 | 先查看保留的历史。要继续取数，打开对应报表，再同步模型 |

本机仅保留最近成功连接或同步的 Desktop 模型的完整快照。成功切换时会释放旧结构和取值缓存，历史会话、分析结果、模板与业务词典仍可查看。想在原会话继续处理同一报表，使用「同步模型」。在已有报表的对话中主动选择其他报表，会开启新对话。

## 查找字段和实际取值

右侧「模型上下文」有三个页签。在「结构」中展开表，点击列或度量值即可将引用插入光标所在位置。「关系」显示连接列、筛选方向及活动状态。「查询」列出当前模型中可读取的 M 查询。

**按业务名称找字段（已包含在 2.0.9）**　在「结构」搜索框输入技术名称，或输入对象词典中已确认的业务名称与别名。例如词典把「实际支出」设为某个金额字段的别名，搜索后可以对照结果中的业务名称与实际表、字段，再点击插入。窄窗口可点对话区上方的「模型字段」，选中引用后返回输入框。

**查字段里有哪些值**　点击列旁的眼睛图标，查看不同取值、出现次数、空值和样例。预览默认最多显示 50 个去重值，可在预览内搜索具体值。从词典进入时，用返回按钮可回到原位置。预览覆盖全模型，当前报表页面的切片器和视觉筛选不会自动带入。需要复现页面数字时，把日期、组织、分类等条件写进问题。

## 建立和迁移业务词典

连接真实报表后，在右侧「模型语义层」核对报表身份与当前 AI 服务。点击「开始梳理模型语义」会向所选服务提交相关模型结构、公式和描述。对象定义分批保存，随后生成待审阅的业务总览。优先确认将要分析的字段和指标。

| 维护视图 | 适合填写的内容 |
| --- | --- |
| 业务总览 | 这份报表解决什么问题、数据粒度、时间口径和常见限制 |
| 业务术语与分析约定 | 解释业务用语，或记录用户未指定条件时采用的默认分析口径 |
| 对象词典 | 单个表、列或度量值的业务名称、含义、单位、别名及适用范围。打开「编辑与确认」，核对后确认定义 |

- **业务术语**可以只写名称和含义。例如解释「结账月」时，保留默认范围「整个模型」即可保存。需要指向具体指标或字段时，可再添加映射。
- **分析约定**至少要添加一个「关联模型对象」或一条「业务筛选映射」。例如约定“未指定月份时按过账月分析”，可关联实际的过账月份列。适用范围决定何时使用约定，选择「指定模型对象」时仍须单独填写映射。「保存为待确认」和「确认业务定义」都使用这条规则。
- 旧词典中缺少映射的约定会保留原文并标为「待复核」。打开「编辑与确认」，补上映射并确认后即可重新用于分析。

模型生成的解释标为候选。可先保存候选、查实际值，确定口径后再确认。对编号 `0257` 一类有前导零的值，说明所属表、字段和值类型。同一编号跨多个分类时，按确认卡上的候选选择，或补充自己的定义。助手在某一轮采用的口径只作用于该任务。

**同一报表有变更**　同步模型后优先选择「仅梳理待更新」。查看保留、新增、修改及删除对象，复核受影响的业务记录。「全部重新梳理」可刷新所有自动候选，仍有效的人工定义会保留。

**关联本机已有词典**　打开「模型语义层 → 词典管理」，找到保存版本，选择「预览差异并关联」。核对对象变化和待复核项，再确认关联。未连接报表时，也可从连接窗口的「管理历史业务词典」浏览、重命名或删除历史版本。

**迁移语义 JSON（已包含在 2.0.9）**　在源模型的「模型语义层」点击「导出语义层」。在目标模型选择「导入语义层」，选取导出的 JSON（上限 64 MB）。预览会列出合并、跳过、保留及待复核数量，核对后再确认。结构和元数据兼容时，合并的条目采用文件中的定义。旧文件里的分析约定缺少映射时，会保留本地已补全的同一条约定。模型结构或元数据存在差异时，当前人工定义受保护，缺失对象会跳过，其余受影响内容需要复核。迁移会话和凭据另需备份整个用户数据目录。

## 使用 DAX 助手

直接输入需求，说明要生成度量值、计算列还是计算表，并列出时间范围、单位、空值行为和实际模型字段。例如「用已有的销售额和毛利额度量生成毛利率，销售额为零时返回 BLANK()，保留报表筛选上下文」。2.0.12 的空白对话还可从输入框上方选择「生成指标」「解释 DAX」或「优化公式」填入提示。

| 结果卡 | 如何使用 |
| --- | --- |
| 静态检查通过 · 未实跑 | 已检查代码结构和模型引用。连接实际报表后，可在结果卡选择「重新实跑本组代码」 |
| Desktop 实跑通过 | 检查本次执行结果。涉及多个度量时，一起验证能覆盖同组的临时依赖 |
| Desktop 行上下文抽样通过 | 计算列在所属表中最多抽样 50 行。确认写入时才执行完整计算 |
| 实跑或验证未通过 | 查看错误、校准差异及后续修订，使用最新候选。自动修复最多两轮 |

长代码可「展开阅读」或切换「自动换行」。使用代码块的「复制」可保留原文和注释。

### 校准与写入

1. 在有实时 Desktop 连接的 DAX 对话中点击输入框上方的「校准」。当前工作区中，按钮位于快捷任务行最右侧。添加最多 10 个同时满足的等值条件，再填一个已知结果和允许的绝对误差。留空筛选可校准全模型。
2. 选择「应用到后续生成」，再发送需求。校准目标是回复中的**最后一个度量值**。例如已知某切片的毛利率为 25%，期望值填底层数值 `0.25`。结果卡会并列显示期望值、实际值和匹配状态。
3. 要写入时先保存报表副本，在通过实跑或计算列抽样的结果卡点击「审阅并写入模型」。核对表达式、名称与所属表，确认时助手按所选目标重新验证。覆盖同名度量值需勾选允许覆盖。计算列和计算表仅支持新建。
4. 派生度量引用本次新建的基础度量时，先写入基础度量。在 Desktop 核对结果并按 `Ctrl+S` 保存 PBIX。一次校准只覆盖给定切片，其他业务场景仍需核对。

## 使用 Power Query

1. 连接含 M 查询的报表，在左侧选「Power Query」，从输入框下方选择目标查询。也可从右侧「查询」查看代码，再点「在清洗助手中使用」。已有会话中更换目标查询会开启新对话。
2. 明确需要调整的步骤。例如「保留现有数据源，去除客户名称首尾空格，把订单日期转成日期类型，列出转换失败的行」。
3. 审阅静态检查和 M 脚本。在 Desktop 的「转换数据」中选中同一查询，先保存原脚本副本，再将新脚本粘贴到「高级编辑器」。核对数据源、数据类型、错误与行数后，选择「关闭并应用」。实际执行和刷新由 Desktop 完成。

## 查询数据并核对结果

在「数据分析助手」中写出指标、日期、比较基准、分组和单位。例如「按过账月比较 2026 年 1–5 月和去年同期的销售额，单位为万元，列出变化最大的三个产品类别」。需要复现某个报表页面时，请补充页面上的筛选。助手对当前连接的 Desktop 模型执行只读 DAX。

- 出现口径确认卡时，选择候选或输入自定义定义，再提交。已确认的条件会用于后续取数。
- 阅读结论后展开 `[Q1]` 等查询依据，核对执行的 DAX、结果和筛选条件。`[F1]` 等记录展示字段查值与样例。遇到空结果、截断或失败时，先看对应提示。计算贡献率时尤其要核对分母是否覆盖完整范围。
- 表格默认预览前 20 行。「放大查看」和「下载本次结果 CSV」使用该次查询保留的结果，最多 200 行、约 24 KB。出现「已截断」时，可缩小范围或改用聚合重新查询。查询超过 30 列会报错，需减少输出列。
- 复杂问题可分批执行。单轮最多 4 批、12 条业务查询，含修复最多 18 次执行。时间或查询额度耗尽时，以本轮已取得的依据判断哪些问题已有答案。

### 保存分析模板与一键重跑

1. 在有查询结果的分析回复下点击「保存为分析模板」。「分析任务与口径」只收录这一轮的提问和这条回复成功查询所用的口径。建议名称概括本轮查询，保存前可以改名。也可在左侧「分析模板」里新建。把影响分析口径的截图信息写入任务。
2. 在「运行参数」中，每行对应一个参数。从分析回复保存时，系统会自动找出可复用的取值。勾选以后想改的项，直接在同一行调整默认值。重复出现的物料号只需填写一次。手动新建时可点「从任务识别」，也可选中任务原文后添加「自定义参数」。
3. 点「保存模板」即可把参数关联到固定查询。一个原值同时出现在几个筛选字段时，在该参数下选择对应字段，再保存。通过「查询代码（高级）」在 DAX 中加入的参数也会出现在这张表里。
4. 连接模板所属报表，点「一键重跑」。参数框会带入模板默认值，可直接点「开始运行」，也可先在框内修改本次使用的物料或日期。没有默认值的参数会带入上次取值，两者都为空时才需填写。
5. 每次都用同一组 DAX 从 Desktop 重新取数。AI 根据当次返回的行生成分析，结果卡保留实际执行的代码、参数和结果。
6. 手动新建的模板可以在首次运行时准备固定查询。旧模板优先采用来源分析或最近同版本运行中的成功查询。

## 对话、图片和导出

| 任务 | 操作 |
| --- | --- |
| 新开或切换对话 | `Ctrl+K` 新建。左侧可按标题搜索最近对话，不同工作区保留各自草稿。切页后当前生成在原会话继续 |
| 停止当前生成 | 点输入框旁的中止按钮，已有文字和结果保留。切换会话时任务继续运行，退出整个应用时本地服务停止 |
| 添加截图 | 点「＋ 图片」、拖入图片或在输入框按 `Ctrl+V`。「截图」打开 Windows 截图工具，框选后需返回输入框粘贴。每条最多 4 张 PNG、JPEG 或 WebP，单张原图最多 8 MB |
| 调整阅读区 | 拖动侧栏分隔线调宽，双击恢复默认宽度。窄窗口通过「模型字段」打开右侧面板（已包含在 2.0.9） |
| 导出会话 | 在对话顶部点下载图标导出 Markdown，包含回复、代码、验证信息、已保留的结果和内嵌图片。单个查询的表格可另存 CSV |
| 删除历史 | 在「最近对话」旁点击该记录的删除按钮并确认，会移除本地相关记录。已写入的报表对象需在 Desktop 中管理 |

### 上下文压缩

点聊天顶部的「上下文」可查看历史消息和字符占用，两项中较高的比例显示在进度条上。分析模式的历史预算为 16 条消息、40,000 个字符，DAX 和 Power Query 为 20 条、60,000 个字符。摘要也计入这两项预算。当前输入、图片、模型结构和本轮查询结果另计。

每个会话默认在历史占用达到 80% 后，于下次发送时自动压缩。积累了较早的历史后，可点「立即压缩」，也可关闭该会话的「自动压缩」。压缩在本机完成，优先保留最近两轮原文。单轮过长时也会整理为摘要。点「查看历史摘要」可核对早期需求、口径确认和查询引用，具体查询的口径例外会跟随该条查询记录。完整消息、附件和结果仍可在会话中查看和导出。

## 备份与恢复

| 运行方式 | 默认用户数据目录 |
| --- | --- |
| 安装版 | `%LOCALAPPDATA%\PowerBIAssistant` |
| 源码版 | 项目根目录的 `data\` |
| 自定义 | 启动前设置 `PBI_DATA_DIR` 指向的目录 |

关闭助手后复制**整个用户数据目录**，特别是 `assistant.sqlite3` 和 `secret.key`。前者保存会话、图片、模型配置、词典和执行记录，后者用于解密 API Key。恢复前先备份目标目录，复制备份到实际使用的位置，再启动助手验证历史与服务配置，并重新连接报表。更改 `PBI_DATA_DIR` 只会改变使用位置，已有数据需要自行搬迁。PBIX 应另存副本。

连接报表与手动查看字段取值在本机进行。运行语义梳理或向 AI 提问时，所选服务会收到任务所需的模型结构、公式、对话、已发送图片、相关字段值或查询结果。备份、Markdown 和 CSV 也可能包含业务数据，应按报表的权限范围保存和分享。

## 常见问题

| 遇到的问题 | 检查步骤 |
| --- | --- |
| 桌面窗口空白或无法启动 | 确认 WebView2 Runtime 已安装，检查用户数据目录的 `assistant.log`。源码版可在 PowerShell 启动查看错误 |
| 模型服务返回 401、403 或 404 | 核对所选配置的协议、API 根地址、凭据和模型 ID，再点「测试连接」 |
| 发送后进入模型语义层 | 当前真实模型还缺少可用的业务解释。梳理对象或录入已知业务定义，然后回原对话发送 |
| 右侧看得到字段，却无法取数 | 快照仍可浏览。打开对应 Desktop 报表并检查右上角状态。若显示「结构待同步」，点击右侧「同步模型」 |
| 预览、校准或分析数字与报表不同 | 对齐指标、日期字段、页面筛选、币种和数值单位。检查空值、前导零以及是否使用 TopN 的截断结果 |
| 能复制 DAX，但没有写入入口 | 检查结果卡是否已在真实 Desktop 通过实跑或计算列抽样。首次写入遇到组件下载失败时，核对官方 NuGet 的访问和代理 |
| 切换运行方式后找不到历史 | 分别确认安装版、源码版及 `PBI_DATA_DIR` 实际使用的目录，再按备份步骤恢复 |
| 图片请求失败 | 核对格式、大小与数量，等待缩略图上传结束，再用支持图片的服务发送 |

反馈问题时，可附上运行方式、界面状态、复现步骤和脱敏后的错误文字。
