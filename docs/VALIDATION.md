## 后台生成与页面切换（2026-11-06）

## 等待状态与文字闪烁修复

- 确认服务器在分析请求中先返回 `reasoning_content`。旧版只读取正文，思考期间没有进度更新；历史中的 `streaming` 消息也未恢复查询，因此会一直显示“正在连接”。
- 新增服务器活动状态、每两秒心跳、等待计时、180 秒单轮总时限、前端空闲超时及历史消息恢复。只显示模型活动状态，不显示内部思考文本。
- 该服务器支持通过 `chat_template_kwargs.enable_thinking=false` 关闭深度思考。原请求复测约 4.6 秒开始正文输出，43 秒完整结束，思考通道字符数为零。
- 实际 HTTP 流配合前端解析模块验证：0.95 秒收到进度、5.69 秒收到正文、26.41 秒完成，返回 3,251 字符。
- 修复前每个文本片段都使用 `innerHTML` 重建整个聊天区并重新触发消息淡入动画。现改为保留消息节点，追加文本、局部更新 Markdown，按绘制帧合并更新；完成时也不会再触发淡入。向上阅读时保留滚动位置。
- 增量渲染与真实模型联调通过：约 1.77 秒开始正文，22.52 秒完成，1,592 个文本片段共 3,246 字符；整个过程消息节点和正文容器保持不变。此检查使用 DOM 测试环境，不代替真实窗口的视觉检查。
