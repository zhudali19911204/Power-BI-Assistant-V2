# Power BI Assistant V2

在 Windows 上连接本机已打开的 Power BI Desktop 报表，用自然语言编写 DAX、整理 Power Query 步骤，或查询模型中的实际数据。助手在本机读取模型，调用你配置的 AI 服务生成回答。需要修改报表时，由你审阅并确认写入。

| 我想做什么 | 选择哪个助手 | 如何使用结果 |
| --- | --- | --- |
| 新建度量值、计算列或计算表，解释已有公式 | DAX 助手 | 核对筛选上下文、单位和验证状态。度量值可用已知结果校准，符合写入条件后再确认目标名称和表。 |
| 清洗字段、解释或优化转换步骤 | Power Query | 选择目标查询，检查生成的 M 脚本，复制到 Desktop 高级编辑器中应用。 |
| 查看趋势、比较分组或追溯变动 | 数据分析助手 | 说明指标、时间和筛选条件。助手执行只读查询，可展开查询依据、查看结果表、下载 CSV，也可保存分析模板供下次重新取数。 |

分析结果在助手中以回复和表格呈现。要将指标做成报表页面或看板，请在 Power BI 中创建视觉对象并设置布局。

## 第一次使用

1. **打开报表。** 在本机 Power BI Desktop 中打开目标 PBIX，等待模型加载完成。
2. **启动助手。** 安装版使用 `PowerBIAssistant-Setup-2.0.13.exe`，运行于 Windows 10/11 x64，桌面窗口使用 Edge WebView2 Runtime。首次安装时，将安装器显示的机器码交给发布者，凭返回的永久或 7 天试用 CD-KEY 完成安装。
3. **配置 AI 服务。** 打开左下角「模型服务设置」→「添加模型」，选择 OpenAI 兼容或 Anthropic Messages 协议，填写服务地址、模型 ID 和凭据，测试后选择「保存并使用」。
4. **连接 Power BI。** 点击右上角的连接状态按钮，按报表名称和路径选择实例。显示「等待 Desktop」时，也可以点这里重新选择。首次使用真实报表进行 DAX 或数据分析时，按提示在「模型语义层」建立业务词典，核对关键指标的含义和单位。
5. **问一个可以核对的问题。** 例如在数据分析助手中输入「请用度量值 `[净销售额]` 列出 2025 年每月的金额，指出最高的三个月」。请换成报表内实际存在的指标。报表页面的切片器不会自动带入对话，所需的日期和分组请写进问题。

暂时没有报表时，可在连接窗口选择「体验示例模型」浏览字段与尝试生成。真实取数、实跑验证和写入需要连接 Desktop。[完整使用指南](docs/USER_GUIDE.md)

## 从源码启动

在 Windows 的项目根目录打开 PowerShell。项目已使用 Python 3.12 验证，桌面运行所需依赖列在 `requirements-desktop.txt`。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\.venv\Scripts\python.exe desktop.py
```

下次可直接运行 [start.bat](start.bat)。前端随本地服务提供，正常使用无需 npm 构建。开发时可用 `.\.venv\Scripts\python.exe desktop.py --browser --port 8765` 在浏览器预览。也可以在启动进程前设置模型服务的环境变量，变量名见 [.env.example](.env.example)。

## 开发与测试

在已创建虚拟环境的项目根目录运行以下命令。前端测试使用 Node.js 内置测试运行器，本次验证使用 Node.js 24。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
npm ci --ignore-scripts
npm test
```

真实 Desktop 查询、模型服务调用和安装升级有各自的联调脚本。修改某一功能时，可先按模块选择对应的自动化测试。[技术架构与开发指南](docs/ARCHITECTURE.md)

## 数据与备份

源码版默认将数据写入项目下的 `data\`，安装版使用 `%LOCALAPPDATA%\PowerBIAssistant`。设置 `PBI_DATA_DIR` 可指定其他目录。备份前关闭助手，复制整个实际数据目录，包括会话、图片及词典所在的 `assistant.sqlite3`，以及解密模型服务凭据所需的 `secret.key`。安装版的 `license.key` 存放在程序目录。

生成回答时，所选 AI 服务会收到任务所需的模型结构、语义、对话和附图。分析或修复时还可能收到实际查询结果、字段值及错误信息。请使用获准处理该报表数据的服务。DAX 写入后，在 Power BI Desktop 中按 **Ctrl+S** 保存 PBIX。
